# Dual-branch-corrosion-component-detection-
Corrosion threatens the durability and safety of industrial steel buildings, making long-term monitoring essential. Vision-based methods offer a low-cost inspection approach, yet complex backgrounds and intersecting members inside these buildings complicate accurate recognition and fully automated corrosion assessment. This study proposes an integrated framework connecting joint segmentation, component-level assessment, and practical deployment. A component-guided dual-branch network (CGDB-Net) integrates global structural context with local corrosion details through multiscale guidance and soft containment, achieving the highest joint segmentation performance among the evaluated models. For model compression, an adaptive multilevel knowledge distillation framework combines a shared encoder with task-specific adapters, improving joint segmentation across four student architectures. The selected student retained approximately 95% of the teacher’s joint recognition performance with 88% fewer parameters. Training-free geometric post-processing automatically constructs component regions and quantifies visible corrosion coverage for grading. Model export, precision reduction, and optimized sliding-window inference improve execution efficiency, with the complete assessment workflow successfully implemented on a physical smartphone. The framework provides a practical basis for automated surface-condition screening and targeted inspection planning for industrial steel buildings.
